# Rights and attribution

This repository archives locally implemented analysis scripts, historical command snippets and source-only notebook exports. It does not assign authorship of all source files to the repository owner and does not relicense external programs or publications.

No blanket software license is asserted by this import. The rights holders should select a license before others rely on a reuse grant. Existing source notices remain intact. Tool names and cited methods identify dependencies; their binaries, vendor directories, database payloads and publications are not bundled.

Notebook code and language-tagged lab-notebook fences are identified as transformed exports in the manifest. Source paths and hashes document provenance. Public accession metadata is supplied to identify external inputs, not to replace the original databases or their terms.
